## 主题设计

深墨绿 `#0E1718` 为页面底色，卡片 `#172426`、次级容器 `#213235` 和底栏 `#121F20` 建立层次。主按钮使用薄荷绿 `#64DDB4` 和深色文字 `#082A23`。正文 `#EAF4F1`，次级文字 `#A4BBB4`；琥珀色保留给待回答与审核提醒，灰色表达未开始及禁用状态。

浅色版的白色同时用于卡片、按钮文字和品牌卡标题，因此按组件语义转换，没有简单反转颜色。表单与未勾选框使用更清晰的边界，选中、待确认、未开始状态同时保留文字和图标。底部操作区与安全区采用一致背景。

本轮沿用原九屏的日文内容、编号、版本和业务状态。首页“進行中のご依頼”已完整显示为一行；详情页缩减局部间距后，末尾说明完整显示在固定操作区上方。浅色原稿没有随本轮改写。

## 验证与实现交接

已逐屏查看实际画布导出：日文、主要按钮、关键说明和状态正常，无明显遮挡。04／07 的完成、当前、待开始状态可区分；08 的勾号仍只表示上传完成；09 保留 `2 / 3`、未选项与禁用验收按钮，修改入口可辨。九张 PNG 均为 390 × 844，文件校验见清单。

色值对比度是数学计算，不代表整应用无障碍验证通过。Inter 为设计指定字体，日文通过回退显示，具体回退字体未验证。动态字号、屏幕阅读器、触控尺寸与真机夜间显示需在 Flutter 阶段验证。

Flutter 已通过语义主题资源实现两套颜色，并在个人设置提供跟随系统／浅色／深色切换；这些工程成果位于 APPClient，本目录的静态设计不包含新增设置画板。详情正文仍需独立滚动，底部操作区尊重安全区；当前静态画框容纳内容不代表大字号或小屏适配完成。

本目录保存可编辑效果图及交接资料；后续 [APPClient](../../../APPClient/README.md) 已实现 Flutter 浅深主题切换及交互 Mock。MasterGo 可点击原型、真实上传与后端接口仍未实现。日本国内、仅开发服务、人工双审后发布、内部授权区别于认证、交付内审与客户验收分离等边界保持不变。

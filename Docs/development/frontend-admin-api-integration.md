# FrontendAdmin 真实 API 联调

更新日期：2026-10-22。用户要求现有 TDesign Vue Next 后台切换至真实业务服务，并清理界面中的 Mock 和演示环境文案。

## 运行链路

浏览器 `127.0.0.1:5180` → FastAPI `127.0.0.1:8001` → PostgreSQL `127.0.0.1:55440/opc_integration`。数据库由 BackendService 访问；前端没有数据库凭据。此链路是本机真实持久化联调，尚非生产部署。原有 PG 中获授权创建的合成业务场景保留。

前端配置 `VITE_API_BASE_URL`，默认使用本机 8001。后端 `/health/ready` 检查数据库和迁移，`/api/v1/capabilities` 返回实际开放能力；顶部显示 API 连接状态，“关于此环境”显示当前接口地址。

启动、账号位置、构建和测试命令见 [FrontendAdmin README](../../FrontendAdmin/README.md)。不要将本机凭据、连接串或令牌写入文档。

## 管理会话

使用 `/api/v1/admin/auth/login` 与 `/auth/me`，确认 admin audience、有效账号及管理角色。令牌仅在内存，每次受保护请求携带 Bearer。刷新后重新登录，业务记录从数据库恢复。退出时调用服务端撤销；会话失效或切换时中止旧请求，阻止迟到响应恢复旧身份或数据。语言及主题仍是唯一持久化的浏览器偏好。

## 业务映射

- 需求列表及详情读取真实客户原文、附件、scope、review 和 publication。技术整理创建并激活新范围版本；不可把本地编辑当作已保存版本。合规和技术审核绑定范围版本；发布依赖同版本有效审核，全部以服务端校验为准。
- `expected_version` 使用当前服务端 `row_version`，不自行递增。409 后提示刷新重试；422、403、网络失败保留真实失败，不生成假成功或样例数据。
- 合作、交付、确认和消息来自统一服务；内部会话和客户会话分别显示。文件下载逐次鉴权，人工安全检查记录真实证据，不声称自动扫描或转换。
- 账号创建、启停、provider 角色、内部承接授权分开操作；初始密码不写浏览器存储。正式认证仍未开放。
- 审计读取后端 `audit-events`，不再在客户端生成本地“审计”。站内通知读取本人记录。
- 工单无后端接口，页面提示暂未开放。AI、邮件推送、支付和 Office/PDF 转换仍未接入；不保留对应的模拟操作。

用户在界面明确提交才执行写操作；连接验证使用只读业务请求，登录和退出仅创建／撤销本次测试会话。浏览器协议测试使用隔离响应，不能作为生产或持久业务写入已验证的证据。

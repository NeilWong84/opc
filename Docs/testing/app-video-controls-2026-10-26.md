# 手机视频预览播放控件（2026-10-26）

用户要求视频预览页补充常用播放控件，包含全屏。

## 实现

- 真实文件页改用共用 `ApiMediaPlayer`，增加当前位置／总时长、拖动定位、快退／快进10秒、播放／暂停、结束后重播、静音／恢复声音与0.5～2倍速。
- 全屏沿用同一个控制器和临时文件，不重复下载或创建解码器；横向视频进入横屏，退出或系统返回时恢复系统方向策略和边到边模式。受系统限制时仍可显示全屏页面。
- 全屏为黑底、安全区布局，提供文件名与退出按钮；音频共用进度和播放控制，不显示视频全屏按钮。窄屏工具栏分行。
- 控件操作和进入全屏先复核当前文件权限。应用切后台暂停播放并隐藏画面；恢复时先复核权限。复核失败或会话变化后清除画面并退出全屏，保留原有文件下载鉴权。
- 界面文案维护在 `file_actions_zh.json`／`file_actions_ja.json`，本轮新增9条中日语言资源。新增控件使用现有播放器依赖，没有引入新视频SDK或后端接口。

## 验证

- Flutter 静态检查通过，全量 **375 项测试通过**。本轮新增8项控件测试，覆盖播放／暂停、定位边界、拖动、静音、倍速、重播、全屏共享状态与返回、权限检查遮挡及撤销退出、音频、小屏横竖与中日亮暗布局。
- 控件单测直接给控制器设置初始化状态，并使用平台命令替身；它们不作为真实文件解码证据。真实Android播放由普通入口应用在可见模拟器检查。
- 工作区既有承接者导航改为五个入口，两个旧测试同步为“承接者总览进入大厅”与“五个入口、无客户提交按钮”的当前断言。
- 普通 `lib/main.dart` API调试APK已构建并覆盖安装到 `emulator-5554`。不包含管理凭据或测试入口，后端与PG未因本次视频改版重启或改写。
- 在普通应用以原客户账号打开 `REQ-00001013` 的真实 `sample-road.mp4`，原生解码显示总时长 `00:05`；内嵌按钮、文件保存入口及全屏画面均已截图人工复核。全屏 UI 层级 rotation=1，实际播放至 `00:01` 后暂停；退出全屏后 rotation=0，仍保持 `00:01`，确认横竖恢复与位置保持。未使用集成测试APK覆盖主设备。

Android证据位于 `APPClient/test_artifacts/video-controls-{inline,fullscreen,playing,return}-device.png` 及 `video-controls-native-results.json`。普通安装包为 `APPClient/build/packages/OPC-0.1.0-android-20261026-api-debug.apk`，附 `.sha256`，本轮哈希前缀 `e4afc67d22c39cc7`。

# APPClient 客户首页改版

日期：2026-10-25。客户首页改为个人项目总览，与完整需求列表分工。本轮直接修改 Flutter，未修改 MasterGo 画布。

## 页面与真实数据

- 顶部展示本人需求及合作项目总数、新需求／继续草稿入口；统计卡片为审核中、进行中、待验收、已完成，点击后进入对应需求筛选。
- 待办分别汇总未回答的澄清、本人尚未确认的当前条款和已公开交付的验收；已确认但等待对方的条款不重复催办。
- 项目按已有协议期限排序，显示真实业务阶段、状态及后续操作。阶段条不代表完成百分比。审核与发布区包含本人尚未建立合作的有效需求。
- 最近反馈仅按服务端 `author_id` 匹配该项目当前 `provider_id`；按消息时间倒序。客户自己、运营、原承接者及身份未知的消息不会冒充当前承接者反馈。正文与名称保持原文。
- 数据来自既有受权限控制的 Repository 快照，无新增数据库表或管理员权限。闭合需求不冒充验收完成，统计仅针对当前客户。
- 支持简中／日语、浅深主题、空记录引导、下拉及按钮刷新。切换页签、返回详情和恢复前台重新读取；失败隐藏总览并提示重试。

## 验证

- `flutter analyze --no-pub`：通过，无问题。
- `flutter test --no-pub --reporter expanded`：330 项通过；包括统计、终止状态、消息身份、筛选、返回刷新、离线、承接者大厅保留，以及 320px／1.4 倍字体的中日浅深布局。
- 普通 `lib/main.dart`、真实 API 配置已在 `emulator-5554` 构建安装；使用本机持久 PG 客户账号登录，实际首页显示 4 项需求、2 个合作项目，以及审核 1、进行 1、待验收 1、完成 0。数量是验证时快照。
- 本机截图和测试日志位于忽略的 `APPClient/test_artifacts/customer-home-*`；已查看 `customer-home-zh-light.png`，顶栏、统计、待办与底部导航显示正常。模拟器可访问 8001 就绪检查（HTTP 200）。

Android 模拟器验证不替代 iOS 构建或生产部署。文件预览扩展属于用户随后补充的独立能力，进展另记。

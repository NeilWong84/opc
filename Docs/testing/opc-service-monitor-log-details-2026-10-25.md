# OPCServiceMonitor 0.2.2 日志详情验证

日期：2026-10-25。用户要求点击日志列表后弹出详情，解决消息受表格列宽限制无法看全的问题。

## 实现

- 四个运行日志 Tab（全部日志、前端、后端、PostgreSQL）单击任意单元格，或选中后按 Enter，打开“日志详情”。每个工作区保留一个详情窗口，重复激活不叠加。
- 展示采集时间（UTC）、来源、级别、输出流、PID、日志 ID 及完整已保存消息；未记录 PID／尚无记录 ID 时如实说明。
- 消息使用只读纯文本控件，保留中文、换行和 HTML 原文，自动折行并可滚动；支持“复制消息”“复制全部”“关闭”和 Esc。
- 从被点击单元格保存的不可变 `LogEntry` 创建快照；实时追加、达到行数上限、清空视图或重新检索不改写已打开的内容。
- 详情展示及复制再次脱敏；保留原 `truncated` 标志并明确说明采集长度限制，不能还原已丢弃的原文。
- 弹窗适配既有明亮／暗黑主题，关闭清理引用，工作区 shutdown 关闭详情。

业务审计的权限、内存会话和不导出规则保持原状；本次改动针对运行日志，不增加业务审计导出能力。

- 入口：`D:\OPC\Tools\ServiceMonitor\dist\OPCServiceMonitor-0.2.2\OPCServiceMonitor.exe`。
- EXE SHA256：`3C9DB11097764883FB776CA2FD7C36EA669A2DF529FFA8BF55F68A77392CF530`。

# 管理后台内部滚动与提示验证

日期：2026-10-25。范围：FrontendAdmin 展示与交互。浏览器验证通过隔离协议数据完成，不写入真实 PostgreSQL。

## 用户要求与实现

- 管理壳固定在视口内，需求、成员、审计、文件队列及工作台主表使用剩余高度，列表内容内部滚动，表头、筛选与分页保持可见。
- 合规、技术整理、发布、项目及交付详情使用模块内部滚动。合规／发布操作栏留在滚动区外；窄屏工作台在内容区内滚动，统计卡片不会挤灭表格。
- `PageNotice.vue` 将页面提示传送到标题下、内容上的统一区域，错误和警告优先显示；弹窗／抽屉使用 `inline` 留在自身顶部。信息、警告、错误及成功消息均可鼠标或键盘关闭，关闭后空间回归内容。
- 关闭提示只改变局部显示。审核、权限和提交条件独立保留；新错误、再次校验或下一次操作成功可重新提示，重复同步校验使用 `reset-key`。
- `ScrollTable.vue` 保留 TDesign Table 的属性、事件、插槽与分页接口，使用官方固定表头及共享 flex 高度布局；卡片内部的 Loading 包装也传递可用高度，避免裁切内容。
- 保留 75／80／85／90／100% 整体缩放、中日双语、TDesign 内置亮暗主题及真实 API。

## 验证范围

新增 `tests/e2e/scroll-layout.spec.ts`，覆盖 1920×1080、1536×864、1024×768 和动态缩小窗口；包含 75／80／100% 缩放、中日及亮暗组合。使用 20 条需求／成员、50 条审计和长技术表单，验证：

1. 只有表体滚动，浏览器页面保持不滚动；筛选、表头、分页位置固定。
2. 顶部提示关闭后表格高度增加；窗口变化后自动重分配高度。
3. 错误关闭及重试、重复无效提交仍显示反馈，不改变权限或产生业务写请求。
4. 长表单底部操作可以通过模块内滚动到达；短屏工作台列表和审计入口可到达。
5. 提示原生关闭按钮支持键盘；弹窗提示留在弹窗顶部。

原 `scale.spec.ts` 的全局滚动场景改为列表／模块内部滚动，保留日期、嵌套年月下拉和折叠导航提示的定位检查。原 `admin.spec.ts` 保留 API 协议、十类页面、中日亮暗、会话与业务校验回归。

## 实际结果

| 检查 | 结果 |

| `npm run build`（含 Vue／TypeScript 检查） | 通过，保留原有大体积包提示 |

最终截图及测量在本机忽略目录 `FrontendAdmin/test-results/scroll-complete/`。另对交付文件队列和三个分辨率的模块可达性完成隔离协议只读检查；确认文件列表可滚、分页和页脚在视口内，1024×768 工作台可在内部滚到审计入口。

关闭一条头部提示后，1920×1080 下需求表体的逻辑可用高度由约 834 px 增加到 906 px；文档高度保持视口高度、`window.scrollY=0`。验证不等于新增或变更后端业务能力。

## 同日补充：复用铃铛通知中心

用户随后明确一般说明可放进现有右上角铃铛。现将九类页面中 17 处审核归档、资料权限、发布／交付边界、认证及筛选口径等说明标为 `PageNotice notification`，不再占用页头。截图中的交付质检归档、证据录入说明及内部检查／客户验收边界三项均已迁移。

铃铛打开同一通知抽屉，提供“页面说明”和“业务通知”。前者使用页面范围内的响应式登记，支持中日语言、逐项关闭和路由卸载清理；角标表示当前页面说明数量，不伪装为服务端未读数。后者继续读取真实通知 API 并标为已读，读取错误在业务通知标签内提供，页面说明依然可访问。注销清理两类内容并屏蔽旧请求回填，页面说明不写入存储或 PG。

错误、权限／前置条件警告、操作成功和未开放功能提示仍按原规则显示；弹窗确认信息留在弹窗内。移走或关闭说明不改变质检锁定、四项清单、证据、审核、发布或权限条件。

新增 `tests/e2e/notification-center.spec.ts`，验证交付三项迁移及关闭不解锁、路由与中日语言、服务端通知已读、即时错误／确认信息、通知接口失败隔离。原内部滚动测试改为从铃铛读取页面说明，同时保留用 API 错误验证关闭后回收高度。

补充验证：构建／类型检查通过；通知中心 5 项、内部滚动 9 项、缩放 13 项及原管理协议 14 项分批通过，共 41 项。通知中心截图在本机忽略目录 `FrontendAdmin/test-results/notification-center-final/`；滚动及缩放记录在 `notification-center/`，原协议语言矩阵最终记录在 `notification-language-regression/`。初次发现登录页隐藏通知面板读取不存在的 `nav.login` 文案，已通过未登录时卸载通知抽屉修复，中日亮暗四组合复验通过。

## 同日补充：消息淡入淡出

按用户要求为 `PageNotice` 及通知中心说明统一增加约 200 毫秒淡入／淡出，关闭时同时收起高度和间距。使用 Vue Transition／TransitionGroup；关闭按钮阻止 TDesign 内部提前隐藏，父级 close 回调延后至离场完成。新的文案或重复校验可中断旧的关闭过程；系统减少动态效果设置继续生效。

新增 `tests/e2e/notice-animation.spec.ts`，3 项浏览器用例通过（约 11.8 秒）：逐帧采样真实不透明度与高度变化、关闭后回收列表空间、键盘关闭、重复错误及离场途中重开、日语暗色通知条目关闭与计数更新、减少动态效果时即时关闭。验证使用隔离协议数据，无真实 PG 读写；输出目录 `FrontendAdmin/test-results/notice-animation/`。

# 管理后台 1920×1080 等比缩放验证

日期：2026-10-22。范围：FrontendAdmin 展示与交互；使用隔离协议数据，不写入真实 PG。

## 实现

- 默认 80%，顶栏可选 75／80／85／90／100%，`opc.admin.scale` 保存偏好，异常值恢复 80%。管理会话仍仅存内存。
- 文档级 CSS `zoom` 统一缩放字体、图标、按钮、间距、表格、表单及 TDesign body 弹层；内容宽度自适应剩余屏幕，固定侧栏及遮罩覆盖完整视口。
- 保留 TDesign 官方明亮／暗黑／跟随系统主题、中日双语。表格操作文字保持单行。
- 通过官方 `popupProps.popperOptions` 扩展，修正 Popper 对触发元素尺寸取整及零高度弹层父节点造成的定位误差，包括页面滚动后的日期弹层。未修改组件库源码。
- 折叠菜单提示通过 Vue 属性透传接入修正；日期面板内部年月下拉通过挂载前设置导出 Popup 的 prop 默认值覆盖。后者是针对锁定的 TDesign 1.20.9 的适配，组件库升级时需运行嵌套日期弹层回归。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| `npm run build`（含 vue-tsc） | 通过；保留已有大体积包提示 |
| `npm test` | 46 项通过 |
| `npx playwright test tests/e2e/admin.spec.ts` | 14 项通过，含十类页面×中日×亮暗和 1024 宽回归 |
| `tests/e2e/scale.spec.ts` | 13 项通过，含折叠导航和嵌套年月下拉的滚动定位 |

最终命令 `npx playwright test tests/e2e/admin.spec.ts tests/e2e/scale.spec.ts --reporter=list --output=test-results/scale-complete` 一次运行 **27 项全部通过**（约 1 分钟）。

缩放用例覆盖 1920×1080 与 1536×864 两种 CSS 视口、中日双语、亮暗主题。第二种视口用于模拟 1920 屏幕在 125% 显示比例下的可用布局空间。验证 100%→80% 实际几何比例、无文档横向溢出、侧栏满高、五档选择、刷新恢复、异常存储回退、下拉对齐、弹窗输入及取消、抽屉遮罩与关闭，以及页面滚动时日期弹层向上展开并可选择日期。

1920×1080 下测得：侧栏宽 232→185.59 px，顶栏高 56→44.80 px，按钮与输入框高 32→25.59 px，卡片内边距 20→16 px，文字 Range 宽 70→56 px。允许小于 1 px 的字体栅格化和布局取整误差。修复后语言下拉横向偏移约 0.034 px。

最终截图与 100%→80% 测量存于本机忽略目录 `FrontendAdmin/test-results/scale-complete/`。嵌套月份／年份下拉的滚动错位由约 82.6 px 修正至不足 0.02 px；折叠导航提示滚动前后保持贴合图标。长列表、长表单仍允许纵向滚动；缩放不承诺将任意数量内容压入一屏。

# 管理后台真实 API 接入计划

用户已明确要求把现有 TDesign Vue Next 后台切换为真实管理后台，并移除界面中的 Mock／演示环境说明。保留 MasterGo 页面结构、简中／日语及 TDesign 内置明亮／暗黑／跟随系统主题。

## 实施范围

1. 接入独立 admin 登录、内存会话、退出及到期处理。统一 HTTP 客户端显示真实错误，禁止失败后返回样例数据。
2. 需求列表、详情、版本整理、澄清、双审核及发布下架使用现有管理 API；修改携带服务端 row_version，不在浏览器伪造审核记录。
3. 项目、消息、交付检查、账号授权及审计连接现有 API；文件按权限下载。工单等无对应 API 的能力显示未开放，不保留本地模拟提交。
4. 更新连接状态、登录账号和环境说明。实际目标为已启动的本地 API `127.0.0.1:8001`，后端连接持久 PG `127.0.0.1:55440/opc_integration`；这不代表生产部署完成。
5. 检查类型、构建、HTTP 会话／错误／版本行为、浏览器中日亮暗和真实接口读取；测试业务变更使用隔离数据，不改写现有持久业务。

## 边界

接单策略、正式认证、支付、AI、文件自动扫描及 Office/PDF 转换仍以服务端实际能力为准。账号、权限、发布、版本和审计由服务端校验。数据库凭据仅在后端，前端不携带。登录令牌不写 localStorage；语言和主题偏好继续保留。

## 分工

- 主代理：HTTP、登录与会话、页面框架、环境配置、文档、整体验证。
- 需求模块：工作台、审核、技术整理、发布以及对应接口适配。
- 运营模块：项目、交付、成员、工单能力状态、审计及对应接口适配。
- 验证模块：协议、会话、错误测试和只读真实 API／浏览器检查。
